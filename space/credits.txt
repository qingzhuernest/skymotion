Interface and solar-system application are original. Gas planet bands are procedural. Reference star positions, visual magnitudes and B-V color indices use HYG 4.1 / David Nash and contributors (CC BY-SA 4.0); see assets/stars-license.txt. The catalog subset is licensed CC BY-SA 4.0.

Detailed planet appearance is generated locally: illustrative terrain, cloud bands, rings and granulation. These are original project textures, not current spacecraft images. See assets/credits.txt.

Observation features: exploration.js samples existing Astronomy Engine vectors for selected-body history and actual distances. The fixed J2000 reference grid and atmosphere edge are illustrations, not new measurement data.

# 自定义交互说明（当前正式版）

## 统一实验台：同屏观察

实验台、关联图解和日行迹现共用一个工作区。原网址仍可打开对应视图；顶部主菜单保持稳定。左侧先选“视图与布局”，展开“天空与日影”“关联图解”或“全年变化”，点击具体图名查看；切到“观测条件”继续调地点、日期、时刻与原来的实验参数。

要在实验台同屏显示天空、地球、高度曲线和日行迹：先打开空间视图，再从语言旁进入自定义，切到“视图与布局”，依次点击这些图名右侧的加入控件。已加入的控件表示移除；点击图名仍用于查看或替换当前画格。更多图可以继续加入，超过四图后向下滚动查看。

“排列与收藏”是左侧菜单中的折叠内容，不再弹出覆盖画面的面板；在这里选择单图、双图、三图或四图，调整排列并收藏组合。“收起菜单”与栏目切换始终保留。完成自定义会保留当前组合，观测条件继续可用；手机使用原参数抽屉。

各图共享地点、日期和公共观测时刻。日行迹另有明确标注的全年固定采样时刻，默认保留钟表时，以显示均时差形成的左右变化；勾选跟随公共真太阳时后，固定真太阳时采样不包含这部分左右变化。改变采样时刻或依据会解除联动，不会偷偷改变下方正在观察的时刻。

日出日落和月出月落方位盘可直接拖动旋转，滚轮或双指缩放；方向标签随盘面旋转，真实方位读数不变。点击升落点跳到对应事件时刻，方向键可旋转，Home 复位，拖动中 Esc 取消。极点或当天没有升落事件时不创建虚构标记。


## 自定义：添加、对照与保存

### 进入与退出自定义

点击语言按钮旁的“进入自定义”。顶部主菜单、原地点与时间控制仍保留；左栏“观测条件”调整原实验，“图中对象”添加和编辑参考。完成后点“完成自定义”，草稿仍在本次会话中保留。

侧栏顶部的“收起菜单”与栏目切换始终保留，滚动时仍可使用；收起后点击画布左侧的展开把手恢复。在“视图与布局”中按类别选择图解；自定义时，点击图名右侧的加入控件组合多图，在“排列与收藏”中调整数量、排列、比例及收藏。手机通过原参数抽屉的关闭按钮返回画布。

展开“排列与收藏”，设置直接显示在左侧菜单中，不覆盖右侧图解；手机也使用原参数抽屉中的同一内容。可选择单图、双图、三图或四图预设，也可从内容目录继续加入其他图。切到“观测条件”即可调整原实验。

日期对照也可以拖动：选择“同一地点 · 不同日期”建立参考，再拖动所选对象的全年日期滑条，或通过日历选定日期。范围随该对象的年份变化，闰年包含 366 天；只改对照日期，不改底部时间栏。

鼠标拖动时连续预览，松手记为一次修改；按一次撤销即可恢复整段拖动。滑条可用方向键微调；拖动未结束时按 Esc 取消，Ctrl/Cmd+Z 撤销。键盘焦点会清楚标出当前操作对象。

需要单独添加参考线、测量、快照或文字时，展开“自由添加工具”。问号按钮按当前图解释时间规则、投影或教学尺度，并提供操作指南链接；添加城市后的列表色标与各图对照颜色一致，重叠标签会尝试避让。

三维天空右下角的“观察”展开相机与显示设置。沉浸模式中，第一次按 Esc 关闭已展开的观察菜单，再按一次退出沉浸。手机参数抽屉切回桌面宽度时，键盘焦点会移到可见的菜单按钮。

同一瞬间的异地换算若超出支持的 1900—2100 年范围，该地点显示不可用，不绘制其太阳位置和日轨迹；可调整日期或经度后继续比较。

### 例一：同一时间，比较不同城市

在太阳实验台进入自定义，点“添加对象”，选择“同一时间 · 不同地点”，选好对照城市，再点“开始这个实验”。系统采用同一 UTC 瞬间进行比较，自动选中新城市，原地点、日期和底部时刻不改变。

选中城市后，可再选另一座城市，或拖动纬度、经度滑条微调；输入框保留精确设置。离开城市原坐标后，自动名称改为“自定义地点＋坐标”，手动命名则保留。“固定同一瞬间（UTC）”比较同一个真实瞬间；“固定当地真太阳时”比较各地相同太阳钟读数，两者不是同一个实验。

添加的城市会同步到相关天空、高度曲线、升落方位和地平面图。切换关联图解仍可选中同一城市修改；同地点的曲线可能完全重合。只有“设为基准地点”才改变原观测地点。

### 例二：同一地点，记录不同时刻

在“添加对象”中选择“同一地点 · 不同时刻”，再点“开始这个实验”，即可加入 09:00 与 15:00 两个时间标记。选中任一标记，拖动它自己的时间滑条继续比较；一次撤销可移除刚建立的这组标记。

时间标记使用当前基准地点的当地真太阳时，支持 00:00—24:00。新增标记不会把底部正在观察的时刻改成标记时刻；日期对照曲线也不会替换全局日期。

### 例三：放一根杆，观察影子

选择“摆放竖杆 · 观察影子”并开始实验；点击地面放置，或点“放在地面中央”。选中杆后，可拖动高度、位置和允许的倾斜角滑条；保持竖直、贴合地面和锁定约束仍有效。底部地点、日期与时刻继续控制光照。

拖动物体底座调整位置，拖动空白地面旋转，滚轮缩放；不需要切换“观察”与“搭建”模式。参考圈、平面和刻度盘用于辅助观察，不模拟物体之间的遮挡。

在“视图与布局 → 天空与日影”中选择空间视图等视角，即可从搭建实验返回天空；实验物体仍保留，并在“图中对象”列表中标注“实验地面”。月球模式也可摆放物体，但不提供太阳专用的城市对照。

### 选择、保存与恢复

点击对象名称查看属性。可移动对象显示手柄，拖动手柄调整；空白处沿用原图的旋转、缩放操作。锁定对象可以选中，但不能拖动。添加或拖动中按 Esc 可以取消。

对象行末的“···”提供“保存本图对象”、复制和删除。草稿仅保留本次会话；“保存本图对象”把所属图参考写入此设备，“保存地面方案”保存实验物体，“布局与收藏”仅保存排列。三者不会互相覆盖，也不会自动同步到其他设备。

读取旧存档时，会整理重复对象编号与无效属性，并保留最多 40 个有效图中参考。若出现存档整理提示，请检查恢复的对象后保存；地面方案中的无效测量会被忽略，其他有效物体仍可使用。

“方案”中可保存、导出或导入当前图参考，导入前选择合并或替换，清空可撤销。下载 JSON 用于备份；更换浏览器或设备不会自动同步本机存档。手机编辑属性时可点“返回对象列表”，顶部“添加对象”保持可用。

自定义保留原实验的地点、日期、时刻与视角；城市和时刻通过现有共享对象联动，各图以来源和对象 ID 区分身份。旧存档继续使用原格式，不复制对象，也不修改天文公式。

新增控件沿用全站字体、颜色与圆角；浅色侧栏和深色画布按钮按所在区域统一。桌面、平板和手机分别验证添加、选择、属性、保存与返回原图；Chromium 自动检查不代替 Safari 真机验证。

其他工具：高度曲线可添加日期对照、参考高度线和两点时间／高度差；月相图可记录指定日期快照，行星伴月可比较角距离和轨迹。实验地面还支持球、参考圈、平面、刻度盘、观察站、标记点和文字；勾选多个物体后，可在“排列所选物体”或“测量与记录”中操作。“对照实验”的 A 固定创建时的条件，B 随当前参数变化。

关闭编辑器后，切换手机宽度或沉浸模式仍可使用原观测控制。Esc 优先关闭当前弹窗；在编辑器中取消放置或返回，在编辑器外不会收起对象菜单。

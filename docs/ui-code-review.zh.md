# 界面代码集中审查

[English](ui-code-review.en.md)

## 已复现并修复

| 问题 | 使用中的表现 | 修正 |
| --- | --- | --- |
| 面板关闭后不再同步侧栏 | 桌面收起对象编辑，再缩成手机宽度，原控制器仍被旧的“图中对象”状态隐藏 | 关闭的编辑器也同步响应式侧栏，清除不适用的导航与显示状态 |
| 沉浸模式残留编辑状态 | 三维页面收起编辑器，进入沉浸模式并退出自定义，再返回普通页面，原参数卡片不可见 | 沉浸切换同时清理旧侧栏；返回普通模式恢复原控制器 |
| 编辑器抢占其他区域的 Esc | 打开仰望天空的轨迹说明，按 Esc 后说明未关闭，背后的编辑器反而收起 | 弹窗与浮层优先处理自己的键盘事件，普通区域的 Esc 不关闭编辑器 |
| 侧栏关联旧隐藏菜单 | 日行迹“观测条件”标签指向旧页面里隐藏的 controls 元素 | 所有页面统一关联当前参数侧栏 |
| 沉浸返回时顶部按钮换位 | 三维页面的自定义和语言按钮被放到主菜单左侧 | 普通模式恢复到主菜单末尾，沉浸模式使用原头部容器 |
| 窄屏抽屉被重复同步关闭 | 快速缩成手机宽度并打开参数，延后的布局同步再次关闭抽屉 | 先同步控件位置；目标容器已正确时不再重置抽屉 |
| 日期属性的全局选择器冲突 | 日历格和四季按钮共用 data-date，打开日历后重绘会把缺少节气参数的格子送进计算，出现 NaN | 缓存季节按钮自己的节点集合，绑定和高亮只处理该集合 |

日期选择器已有独立的键盘保护，检查中保留该行为；轨迹说明使用原生对话框关闭和焦点恢复。

## 合并的重复实现

`customization-mode.js` 统一实验台、关联图解、日行迹和三维页面的自定义开关标签、启用状态、退出校验和状态通知。各页面适配器只保留自身的布局、路由和嵌入图解处理。无效输入阻止退出；重复进入不重复派发状态变化。

`ui-palette.css` 继续作为公共控件颜色的定义来源。普通模式与沉浸模式保留原有绿色操作主色。科学画面的颜色与坐标计算没有合并进界面状态。

移除了永远隐藏的旧“编辑／观察”模式按钮，以及没有读取者的菜单栏目缓存。对象草稿、保存格式、跨图城市与时间对照保持原规则。

## 源码职责与清理

| 文件 | 职责 |
| --- | --- |
| ui-palette.css | 公共界面颜色角色 |
| customization-mode.js | 所有页面的模式开关、退出入口校验和状态通知 |
| diagram-tool-definitions.js | 工具种类、字段、范围与中英文名称，不绑定 DOM |
| diagram-tools.js | 对象状态、历史和编辑器；工具库、列表、属性面板各自渲染，属性统一提交 |
| custom-layout.js | 组合布局、收藏与布局手势 |
| scene-builder.js | 实验物体、实验地面与其测量和保存 |

移除废弃的模式按钮、重复入口、旧锁定变量和无人读取的菜单缓存。清理了 260 处在相同选择器与条件下被后续覆盖的属性定义，保留主题、断点和兼容声明。按照项目现有格式规范展开压缩写法，便于直接阅读和审查；格式化和 CSS 分析工具只用于维护，不随网站交付，也不是运行依赖。

整理前后对照四个页面、两种屏幕尺寸、普通／自定义模式共 16 组实际控件计算样式，颜色、字体、边框、间距和显示状态一致。后续修改应直接进入所属模块，不继续在文件末尾添加覆盖层。

## 验证与范围

`tests/interaction-audit.cjs` 覆盖上述故障链、弹窗键盘归属、四个科学页面的退出校验和状态通知。既有检查继续覆盖城市联动、对象编辑、布局、双语、损坏存储、打包与部署；`tests/ui-palette.cjs` 检查公共颜色来源和实际控件联动。

检查使用 Chromium 自动化与桌面、平板、手机尺寸的浏览器画面。它不代表所有 Safari 真机、GPU 或所有可能的操作序列均已验证。后续新增菜单应复用公共开关与颜色角色，并为新故障补充实际操作回归，不再叠加另一套状态或色号。

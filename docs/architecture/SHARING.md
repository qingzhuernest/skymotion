# 实验分享与深链接

## 使用入口与范围

实验台“视图与布局 → 排列、收藏与分享 → 复制当前实验分享链接”在普通与自定义模式都可使用。分享的是复制时的快照，接收者打开后暂停播放；不会创建本地收藏或同步账号。无需服务端、登录、上传文件或生成短码。

支持太阳/月球模式、观测状态（含地点、日期、时刻和时间依据）、最多六个图位的排列/比例与独立天空视角、当前天体可保存的图中对象和地面场景。沿用完整实验的对象验证与恢复协议。未完成或不合法的编辑不能被悄悄丢弃。个人设置、搜索对话、三维天空与独立地升观察器不在此协议内；编辑专属图位也不会被偷偷替换为其他图位。

链接长度超限时明确失败；可记录观测条件并用现有对象/场景 JSON 导出进行分享。不自动调用第三方短链或二维码服务。教师可用学校的二维码工具转换生成的链接；未宣称所有投影和二维码尺寸都能可靠扫描。

## 编码协议

片段为 `#state=1z.<base64url>`，`1z` 表示 v1 的 deflate 数据；`1j` 表示未压缩 JSON 的 UTF-8 字节，供缺少 CompressionStream 的浏览器处理短快照。编码没有加密，也没有身份认证。

JSON 包含 `version: 1`、`layout`、`experiment` 与布尔字段 `editing`（缺省false）。后者继续使用 `captureComplete()` 的 v1 body/conditions/references/ground 结构。组合图的 `selected` 为 `solarCompare`；独立图保留其规范视图 ID（例如 companionModule），不强行把不可组合的视图塞进布局卡片，并保留教师的普通/自定义模式，让自定义对照对象直接可见。分享会关闭与独立三维页面的联动。

- URL 总长最多 2,800 字符，含域名和路径。数据过大不能降级为不完整的分享。
- 编码前与流式解压后均限制 600,000 字节；解压逐块计数，超过即取消 reader。
- 版本、Base64url 字符、UTF-8、JSON、天体、布局及现有实验结构逐层验证。
- 浏览器必须支持当前编码对应的解压格式；不支持则显示重新复制或 JSON 的恢复建议。
- 网址保留当前部署域名与子目录，统一回到对应语言的 lab.html；清除旧控制参数，避免冲突。兼容干净路径与尾部斜线。

片段不随 HTTP 请求发送，但链接本身包含地点、标签和对象说明，任何拿到链接的人都能解码。复制、转发及使用第三方二维码工具时应按可读资料处理，不能当作秘密。没有云端撤回；之后修改原实验不改变旧链接。

## 启动与事务

分享脚本在既有路由改写 Hash 前捕获原片段。DOMContentLoaded 的所有状态所有者注册结束后解码；同页切换分享 Hash 也执行相同流程，并用请求代数隔离迟到的解码。先验证目标天体及其参考对象，不为验证而切换当前状态。通过后复用原有完整实验恢复事务：条件 → 参考 → 地面 → 布局 → 普通/自定义模式 → 呈现；全部检查点在任何应用前捕获。

事务失败时恢复观测、对象、布局、当前天体的场景桶与撤销栈；无效数据不会先覆盖有效实验。恢复不写入五项收藏列表。片段随后由工作区路由接管，用户仍可正常切换图位和使用浏览器历史。

剪贴板写入在用户点击时立即开始，文本由 Promise 提供，以兼容 Safari 的用户激活要求。拒绝访问时在原折叠组内显示只读、可选择的链接，不新开弹窗。状态消息为 live region；重试沿用同一个按钮。

## 教学任务入口

学习指南的 11 项任务各保留一条主要操作链接。统一实验台内容使用 `lab.html` 的 `body`、`control`、`sidebar`、`edit` 查询参数与视图 Hash；例如 `lab.html?body=sun&control=conditionsMenu#chartPanel` 同时定位高度曲线与日期/地点设置。它不覆盖现有具体数值，也不冒充完整实验快照。

日晷（sundial.html）、地升（lunar/index.html）和三维天空（space/index.html）保留实际独立页面。diagrams.html 与 analemma.html 等旧入口继续兼容，指南中不再与相近功能按钮重复并列。

## 验证

`tests/experiment-share.cjs` 覆盖实际电脑场景到全新手机/英文会话、UTC 时间依据、布局、参考和地面物体、月球模式、跨天体失败回滚、手动复制、压缩兼容、无效片段与压缩炸弹边界。`tests/experiment-save.cjs` 验证本地收藏恢复不受破坏；`tests/document-action-links.cjs` 检查 11 项任务唯一入口及目标视图和面板。

测试使用 Chromium；真实 iPad/Safari 剪贴板权限、系统二维码识别及课堂投影距离仍需设备验证。CompressionStream 使用浏览器能力，不增加网络压缩依赖。

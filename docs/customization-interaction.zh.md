# SkyMotion 自定义交互规则

适用范围：GPT Site 预览 71。正式网站未更新。

## 进入与退出

实验台和关联图解的“进入自定义／完成自定义”放在语言切换旁。正常模式保留原菜单、图解和共享时间栏；进入时保留当前图、地点、日期、时刻和视角。新增参考和搭建工具仅在自定义开启后显示。布局工具仅在关联图解的四图对照中出现。

完成自定义收起编辑界面和参考图层，保留草稿。刷新或直接打开链接默认正常模式；在实验台和关联图解之间点击内部链接时，仅这次导航延续自定义状态。新模式不建立另一套科学条件。

## 原控制与对象编辑

- 桌面左栏的“观测条件／图中对象”原位切换原参数与参考编辑，两个任务保留各自状态；底部原日期、时间和播放始终可用。
- 实验台保留空间视图、俯视日影、地平视角、仰望天空四个原按钮。换视角不会删除参考。月球模式使用原有月相／天空入口。
- “移动图中标记”调整参考，“按原图操作”恢复原图旋转、缩放等手势。
- 添加后直接显示属性；列表可用方向键、Home/End 选择，Enter 编辑。属性里的 Esc 放弃未应用的字段输入并返回列表。输入法保持原生行为。
- 每个对象行在名称、显示勾选之后提供“···”，内含保存、复制和删除。底栏只显示状态，不重复放这三个按钮。菜单支持方向键和 Esc。
- 无效字段阻止保存、完成自定义和任务切换，并定位到错误。修改可撤销、重做；拖动取消会恢复数据。
- 手机保留原参数抽屉，参考编辑使用底部面板，入口和菜单均可触摸操作。

## 城市与时间在原图内对照

在地球昼夜图或实验台天空图添加“观察点／城市”，输入经纬度、名称。可见城市自动参与实验台天空、高度曲线、升落方位及地轴地平面图对照。它们使用一致的城市颜色；隐藏、删除或修改后同步刷新。

原时间规则区分：

- **固定当地真太阳时**：各地使用相同真太阳时，比较当地同一太阳钟时刻。
- **固定 UTC 瞬间**：各地使用同一实际时间戳，读数换算当地真太阳日期和时刻。

城市对照不改变原基准地点；“设为基准地点”才明确更新原观测地点。理想赤纬模型只提供太阳时比较。

在实验台天空或高度曲线添加多个“时间标记”，便可在原图中比较同一地点不同时间。标记同步到天空、高度、方位及地平面图，地球昼夜图显示对应时刻的直射点，使用当天基准地点的真太阳时，不改变正在播放的时刻。日期对照曲线仍属于所添加的图，不自动替换全局日期。当地地平线以下的天空轨迹使用虚线，方位展开接缝断开，仰望天空只显示可见半球。

同一标签页内的跨页草稿通过会话存储保留。明确“保存”才写入本机长期存档；文件页可导出、导入、合并、替换和可撤销地清空。

## 摆放实验物体

实验台天空的添加工具中选择“摆放实验物体”，或在关联图解进入“搭建实验”。支持杆、球、圈、参考平面、刻度盘、观察站、点和文字。可调整位置、尺寸、倾斜、贴地和竖直约束；多选排列、距离／角度测量、影尖记录及冻结条件对照继续可用。实验台点击原视角按钮即可回到天空，物体方案保留。原地点与时间控制继续可用。

杆和球采用几何投影；参考物不遮光，不模拟物体相互遮挡。科学图的示意尺度与实际距离须按图中说明理解。

## 统一视觉与检查范围

新增控件复用原 `--design-*` 颜色、边框、圆角和中英文衬线字体；不另设蓝紫或绿色 UI 主题。科学图用于区分数据的颜色保留。

回归覆盖原控制、对象行菜单、字段恢复、会话草稿、跨页状态、城市时间规则、四图同步、实验搭建以及中英文桌面／手机布局。浏览器自动检查使用 Chromium；尚未完成 Safari 真机验证。


线上简洁地址：跨页状态同时识别 `.html` 与无扩展名地址；刷新仍回到正常模式。


## 实验台就地设置（预览 70）

进入自定义后，在原“日期与地点”菜单内直接展开“对照地点与时刻”。“记录当前时刻”添加原天空图上的时间标记，输入 HH:MM 可调整；支持 24:00。“添加地点”从原城市列表选取，展开城市名称可修改名称、纬度和经度。这里也列出关联图解中创建的城市与时间标记，可直接修改而无需跳页。原 UTC／当地真太阳时选择器复用在此，不新增另一套时间规则。各行的显示勾选与“···”保存／复制／删除继续可用；撤销／重做操作最近修改的来源图。原地点、日期、时间与视角不会因新增对照而改变。手机在原设置抽屉中完成这些操作。


## 固定导航层级（预览 71）

全站主导航固定入口与顺序，切换太阳／月球不再隐藏“日行迹”；当前页高亮兼容中英文地址。桌面进入自定义后，侧栏“观测条件／图中对象”在整个模式内常驻，不依附于某张图的编辑器。收起编辑器只更新下方内容，提供继续编辑入口；切换图解只更换编辑目标和工具内容。添加／对象／文件保留用户选中的栏目，不再按有无对象自动决定栏目。无对象时显示空状态。明确新增对象仍会展示其属性，以便继续编辑。手机保留原底部工作台，同时保留栏目选择。退出自定义恢复原正常模式。


## 第 72 版：入口与空白起点

- 独立三维太阳系页增加与实验台相同的顶部“进入自定义”开关，和语言切换放在一起；沉浸观察时同一组按钮移入顶部控制栏，保持可用。嵌入视图沿用父页面模式，不重复提供入口。
- 实验台自定义的“地点与时间对照”放在原观测菜单顶部，直接显示“同一地点 · 不同时间”和“同一时间 · 不同地点”。后者明确区分同一 UTC 瞬间和各地相同真太阳时，保留原时间规则选择器。添加的地点和时间仍使用共享图解对象，不改变基准观测条件。
- 同一面板提供“摆放杆、球与参考圈”入口。新搭建从空白地面开始；双杆或圆周四杆示例只在明确选择时载入。保留用户已保存的方案。
- 原天空图中央小圈是原有观察者标记，不是自定义自动添加的圆圈。恢复的用户对象仍可在图中对象中编辑或删除。

太阳和月球搭建页都不再默认生成参考圈；背景直接沿用原图 `.ui-plot` 的颜色，地面、网格和文字使用原图的灰蓝配色，移除独立的墨绿渐变。恢复已有方案时在介绍下方明确提示，可选择空白地面或删除物体。

实验台月球模式保留同一位置的“实验物体与参考”入口，可直接进入摆放工具；不显示仅适用于太阳的城市与时间对照。

### 添加对象的入口与触屏摆放

在“图中对象”列表旁点击“添加对象”，即可继续新增，无需先关闭属性。太阳空间图可先选择城市，再添加观察点；原地点保持不变。相同地点的曲线会重合。文字、重点圈等工具会显示摆放提示：点画布选择位置，或点击“直接放在图中央”。添加成功后进入对象属性；保存、复制与删除仍在对象行末的更多菜单内。

教学起点与预备知识

开始操作时，在顶部选择太阳或月球；打开左侧“视图与布局”，展开“天空与日影”选择空间、俯视、地平或仰望视角。选择其他图解后仍可从同一目录返回天空图。地点、日期与时刻在各图间共享；进入自定义只启用编辑工具，不替代原来的观测控制。

本指南面向教师组织课堂和学生自主探究。先提出可检验的问题，再用功能手册查操作入口；每个任务都要求固定条件、改变变量、记录证据和解释结果。

实验前必须说清的四个约定

  • 地点是实际观测条件；相机转动只改变看图方向。要移动地点，应使用经纬度、地点滑条或明确的观察点移动工具。
  • 高度以几何地平线为0°，天顶为90°；方位从北起顺时针，东90°、南180°、西270°。
  • 下方当前时刻、日行迹全年采样时刻、三维UTC日期和地升地落的独立飞行控制，不应当作一个相同的钟。
  • 真实日期、理想太阳赤纬实验和圆轨道地升模型的假设不同；比较结果前先写明模式。

怎样安排一节课

一节约四十分钟的示例

  1. 导入：提出一个日常问题，让学生先预测，例如冬天正午影子是否更长。
  2. 建模：说明地点、日期、时间依据与所用视图，演示一次只改一个量。
  3. 小组探究：分配记录者、操作者和解释者，各组用相同表格进行三个或更多对照。
  4. 交叉验证：要求另一张图或另一个读数支持同一解释，避免仅描述动画。
  5. 交流与迁移：让学生解释一个新纬度、另一半球或日期变更线附近的情形。
  6. 退出条：提交结论、证据、控制条件和一个模型未包含的因素。

把自定义用作教学工具

自定义应服务于一个问题。先确定要比较的条件，再添加城市、日期曲线、时刻、参考线、测量或实验物体；不要为了填满画面同时加入所有工具。

  1. 先保留基准条件，再选择同一地点不同时刻、同一地点不同日期或同一瞬间不同地点。
  2. 选中对象时，利用跨图突出核对同一条证据；多图中的当前图位由边框标明。
  3. 给对象和收藏使用带条件的名称，例如北纬40度、夏至附近、固定真太阳时。
  4. 提交完整实验时，在排列与收藏勾选连同观测与对象保存；同时导出文字记录，说明设备本地保存的范围。

任务一：太阳一天怎样运动？

探究问题

同一天、同一地点，太阳高度和方位怎样随时刻变化？

先固定条件

选择北京或输入约北纬40°、东经116°；选择接近北半球夏至的日期。使用日期观测，先暂停播放，保持地点和日期不变。下方日内时刻使用当地真太阳时。

操作与记录

  1. 在天空与日影图选择空间视图，再加入全天高度曲线。先预测哪一时刻最高。
  2. 依次调到06:00、09:00、12:00、15:00、18:00；记录高度、方位和是否位于地平线上方。
  3. 将时刻移到曲线过零附近，核对升落方位图中的事件。点击升落点可跳转事件时刻。
  4. 播放日内时刻，观察太阳的日轨迹；暂停后用时间标记留下两个要比较的位置。

应观察到什么

太阳高度先升后降；几何地平线对应高度0°。当地真太阳时12:00对应太阳上中天，但太阳方位不应在所有地点和日期都预设为正南。

怎样解释

日变化主要来自地球自转。轨迹是观察者天空中的视运动，不能用画面中太阳离杆子的屏幕距离推算真实日地距离。

检查是否理解

用高度曲线和空间图各提供一条证据；说明为何地平线下的虚线不表示地下有一条真实轨道。

任务二：同一地点的季节差异

探究问题

为什么同一地点的正午高度、昼长和日出方位会随季节改变？

先固定条件

固定同一纬度和经度；固定当地真太阳时12:00。使用真实日期。比较分日与至日附近的日期，实际分至点时刻以星历为准，不把固定公历日当作每年的精确节气。

操作与记录

  1. 将地球与昼夜、全天高度曲线、升落方位和地轴与地平面放在同一工作区。
  2. 按春分、夏至、秋分、冬至的顺序设置日期；记录正午高度、日出与日落方位和昼长。
  3. 用日期对照曲线保留一个季节，再调整公共日期比较另一个季节。
  4. 改到南半球相同绝对纬度，重复观察，并比较两半球的季节关系。

应观察到什么

同一地点的日轨迹会随日期上下变化，升落方向也改变。南北半球的季节变化相反；赤道、回归线和高纬地区的表现不同。

怎样解释

地轴倾斜使太阳赤纬随公转变化。正午高度可用90°减去纬度与赤纬之差的绝对值解释；该式描述上中天高度，不自动给出天体位于南方还是北方。

检查是否理解

解释地球与昼夜图中的直射点纬度如何与曲线峰值对应，并指出比较时必须固定哪些条件。

任务三：纬度与昼夜分布

探究问题

在相同日期，不同纬度的太阳轨迹和昼长有何差异？

先固定条件

固定日期和经度。先比较相同当地真太阳时，再单独研究同一UTC瞬间，避免把两种比较混在一起。

操作与记录

  1. 在自定义中选择同一时间、不同地点，添加赤道、中纬度和高纬地点。
  2. 明确选择固定当地真太阳时，记录三个地点的正午高度及升落情况。
  3. 拖动一个地点的纬度滑条，观察其自动名称、曲线、位置和图例一起更新。
  4. 观察出现无升落事件的高纬日期；用高度曲线判断全天在地平线上方还是下方。

应观察到什么

高纬地区可能出现极昼、极夜或地平线相切。没有事件标记不等于功能损坏；极点的正北方向也不具有唯一性。

怎样解释

太阳高度取决于纬度、赤纬和时角。纬度决定当地地平面相对地轴的方向，不能仅靠太阳在屏幕上的上下位置判断真实高度变化。

检查是否理解

分别写出普通升落、极昼、极夜和相切的判据，并用曲线而非只凭一帧图像说明理由。

任务四：同一时刻与同一瞬间

探究问题

北京和另一城市都显示12:00，是否在观察同一个真实瞬间？

先固定条件

使用真实日期观测，固定基准地点、日期和时刻，添加一个经度差异明显的城市。先不改变原观测地点。

操作与记录

  1. 选择固定当地真太阳时，比较两地相同太阳钟读数下的高度。
  2. 切换为固定同一瞬间UTC，观察对照城市的当地真太阳时及必要时的日期变化。
  3. 将经度滑条移到日期变更线两侧，记录日期和太阳高度，保持纬度不变。
  4. 选中一个城市，在各图核对同色突出项；只有确实要改变基准时才使用设为基准地点。

应观察到什么

相同当地真太阳时通常对应不同UTC瞬间；相同UTC瞬间在不同经度可有不同当地真太阳时，甚至不同日期。

怎样解释

经度决定相对太阳子午圈的方向。这里的真太阳时不是手机的法定时区时间；夏令时、行政时区和均时差需要分别说明。

检查是否理解

画出一个两列记录表，分别标记固定UTC和固定真太阳时，不能只写同一时间。

任务五：杆高、影长与影尖轨迹

探究问题

影子为什么改变方向和长度？提高杆高会改变太阳高度吗？

先固定条件

固定地点、日期和地面，先使用竖直杆。水平地面上的影长关系适用于太阳在地平线上方且杆竖直的情况。

操作与记录

  1. 打开俯视日影，观察09:00、12:00、15:00的影长和方向。
  2. 开启影尖轨迹，再调节显示放大倍率；分清改变显示倍率与改变杆高。
  3. 进入搭建实验，放置两根不同高度的竖杆，保持位置和倾斜规则明确；用测量工具比较。
  4. 改变日期并保留一个参考，比较影尖轨迹；太阳接近地平线时单独记录显示范围的限制。

应观察到什么

影子方向与太阳水平投影相反。相同太阳高度下，竖直杆的影长与杆高成比例；夜间不应有直射阳光产生的地面影子。

怎样解释

太阳高度为h、杆高为H时，平地影长L=H/tan(h)。h接近0°时影长很大，画面裁剪不意味着影子真的终止在边缘。

检查是否理解

分别说明改变杆高、相机缩放、显示倍率会改变什么，并解释为什么不能用截断影子验证公式。

任务六：日晷为什么可以计时？

探究问题

水平日晷和赤道日晷为何采用不同的刻度布局？

先固定条件

进入观测条件中的日晷相关控件或日晷网址，固定地点与日期，区分太阳时刻度与带固定时区偏移的钟表时解释。

操作与记录

  1. 分别观察水平式与赤道式，识别晷针、晷面与地轴的关系。
  2. 在几个整点暂停，比较影线与时刻标记；记录不能得到有效交点的情形。
  3. 只改变纬度，观察水平日晷刻度和晷针方向怎样变化。
  4. 切换到另一季节，检查赤道晷面受光的正反面及日照可用性。

应观察到什么

水平式刻度通常不等距；赤道式利用与地球自转轴垂直的平面表达时角。不同装置的刻度不能直接混用。

怎样解释

装置几何决定光线与晷面的交点。太阳时、钟表时和经度改正不同，模型设置的固定偏移不自动处理夏令时。

检查是否理解

指出至少两个导致实物日晷读数与手机时间不同的原因。

任务七：月相与月球的升落

探究问题

月相变化与月球一天内在天空中的运动，是同一件事吗？

先固定条件

选择月相模式和一个真实日期，先固定时刻按日观察月相，再固定日期观察日内位置。

操作与记录

  1. 将月相与关系、照明比例、月出月落和天空视图放在一起。
  2. 逐日记录月面照明比例、相位位置和可见亮面朝向。
  3. 返回一个日期，拖动日内时刻，比较月球高度变化及月出月落事件。
  4. 拖动升落事件点，观察系统反求附近日期，说明这次操作改变了日期，而不是随意旋转方位盘。

应观察到什么

月相主要由日地月相对几何决定。当天可能只有月出或只有月落事件；月球并不保证每天在相同钟点出现。

怎样解释

月球亮面方向还与本地朝向和观察视角有关。月相示意中的距离和大小可能经过教学放大，不能据此判断日月食。

检查是否理解

用两组记录分别解释月相月周期和一天内高度变化，并指出二者各自应固定哪些条件。

任务八：行星伴月与角距离

探究问题

天空中看起来靠近的两个天体，在空间中也一定靠近吗？

先固定条件

固定地点和真实日期，选择月球与一个行星。角距离是两条视线夹角，不是公里距离。

操作与记录

  1. 打开行星伴月或仰望天空，选择比较行星，并确认两者是否都位于地平线上方。
  2. 按日调整日期，记录角距离；若使用搜索，先读清地点、时间和搜索日期范围。
  3. 用时间标记或位置记录保留结果；转头寻找天体时不要同时移动观测地点。
  4. 打开三维太阳系核对两颗天体的空间位置，解释投影接近与真实距离的区别。

应观察到什么

角距离小只表示天空中的方向接近。低于地平线、夜间条件或真实能见度仍影响实地观察。

怎样解释

仰望画面是当地天空方向投影，三维太阳系则是经过比例处理的空间示意；两者可以相互解释，但读数不能混用。

检查是否理解

解释一次伴月搜索结果不能保证肉眼可见，并写出还需核对的观测条件。

任务九：日行迹为什么像“8”字？

探究问题

每天同一个钟点记录太阳，为什么不只得到一条南北方向的线？

先固定条件

选择真实日期、固定地点，并把日行迹采样依据设为固定钟表时；明确UTC固定偏移。全年采样时刻与下方当前观测时刻是两套不同控制。

操作与记录

  1. 打开日行迹，记录全年曲线的上下范围、左右变化及当前日期点。
  2. 只改变全年固定采样时刻，观察曲线在当地天空中的位置变化。
  3. 改用固定真太阳时，或勾选跟随下方真太阳时，比较均时差所致的左右分量。
  4. 在理想成因实验中分别调整地轴倾角和轨道偏心率，每次只改一项，再与真实日期模式比较。

应观察到什么

真实钟表时采样同时包含赤纬变化和均时差影响。固定真太阳时会去掉由均时差引起的时角左右变化，但不同投影仍可能产生几何弯曲。

怎样解释

地轴倾斜与轨道非圆共同影响太阳在固定钟表时的方向。理想成因模型用于隔离变量，不等同于真实星历的另一种显示皮肤。

检查是否理解

在记录表中明确写出采样依据、UTC偏移、采样时刻、地点与模型模式，缺一项就难以复现实验。

任务十：月球上为什么有地升地落？

探究问题

绕月飞行时看到的地升，是否等于站在固定月面上每天看到地球升起？

先固定条件

在月相模式进入地升地落。这里是独立的圆轨道教学模型，绕月角度、飞行速度和日地月构型由本模块控制，不由下方真实日期星历直接决定。

操作与记录

  1. 选择绕月观察，点击看地升；同时看轨道示意中的观察位置和宇航员视角。
  2. 暂停并拖动绕月位置，说明月面边缘如何遮住或露出地球。
  3. 改变高度，比较地平线下俯和地球出现位置；若地球离开画面，使用朝向地球。
  4. 切到固定月面模式，再改变构型，比较地球方向与亮面变化。

应观察到什么

绕月运动改变视线与月面边缘的关系。固定近地侧月面在同步自转简化模型中不会每天看到地球升落；地球亮面仍可变化。

怎样解释

模块未模拟真实月球天平动、地形遮挡和精确任务轨迹；不能把教学飞行速度当作真实轨道周期。

检查是否理解

画出观察者、月球边缘和地球的视线关系，并解释转头、绕月移动和改变光照构型分别改变什么。

任务十一：用空间模型解释天空视运动

探究问题

日心空间位置、地球观察方向与当地天空读数怎样联系？

先固定条件

进入三维天空，固定日期；读取时间栏的UTC标注。天体大小、行星轨道距离和月地距离采用不同教学显示尺度。

操作与记录

  1. 在太阳系总览中选取地球及另一颗行星，比较说明中的物理量与图中显示尺寸。
  2. 切换日地月关系，识别太阳方向、月球照明和地球姿态。
  3. 打开原图对照或当地观察相关视图，核对同一UTC瞬间的太阳或月球方向。
  4. 使用参考平面、距离线、角度弧或说明标签表达证据；涉及额外天体时读清其模型和显示范围。

应观察到什么

相机旋转不改变物理位置。显示距离可被压缩，但物理向量和读数仍采用各自标明的单位。

怎样解释

从空间位置转换到当地天空，需要考虑观测者位置、地球姿态和坐标投影；不能仅凭三维画面上的两点距离判断天空角距离。

检查是否理解

说明一个模型有意夸大的量和一个仍由真实星历计算的量，并说明用途不同。

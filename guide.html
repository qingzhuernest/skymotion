先完成一次观察

做实验前先写一个问题，确定保持什么、只改变什么，以及从哪项读数判断结果。本指南提供实际操作路径、任务单和记录表；项目介绍说明开发目的、数据依据与适用范围；开发说明供维护者查看代码和验证方式。

  1. 进入实验台，标题旁选择“太阳”或“月相”；确认标题、地点、日期和时刻。
  2. 在“参数 → 日期与地点”选择地点；需要精确坐标时展开“精确调整经纬度”。纬度北为正、南为负，经度东为正、西为负。
  3. 暂停播放，先用图形下方日历选完整日期，再用时刻滑块、输入框或±5分设定时刻。主实验时刻是当地真太阳时。
  4. 记录初始读数，只改一个条件；再换图核对，最后写明结论成立的地点、日期和时间依据。

五分钟入门：北京的一天

  1. 打开实验台，选“太阳 → 空间视图”，地点选北京，日期选本年的春分；保持“日期观测”。
  2. 暂停播放，在下方时间框依次输入06:00、09:00、12:00、15:00、18:00，每次读太阳高度和方位。
  3. 把太阳位置与地平线比较：高度大于0°在地平线上方，小于0°在下方。不要把06:00或18:00当作必然精确的升落时刻，实际结果以日期星历和升落提示为准。
  4. 切到“地平视角”或“全天高度曲线”，核对同一时刻；回到12:00，再只改日期为夏至和冬至。
  5. 写一句带条件的结论，例如“北京、相同真太阳时，夏至太阳比冬至高”。随后换到南纬，检查结论适用的范围。

先提出预测，再操作验证。若结果不同，先检查地点、日期、时间依据和模式，避免为了得到预想图形同时改动多个参数。

控制区、菜单与撤回

先找到图形、时间条和参数

常用日期和时刻在图形下方，参数菜单负责地点、计算方式、辅助显示和观察设置。不要到菜单里寻找第二套相同日历。宽度大于760像素时默认显示左侧栏；点击侧栏顶部“收起菜单”扩大图形，点击左边缘箭头恢复，也可在手柄处拖动开合。

760像素及以下窄屏点击标题旁“参数”打开侧拉菜单。菜单正文上下滑动用于阅读，标题处左滑用于关闭；也可点关闭按钮、外部遮罩或按Esc。设置后收起菜单，继续使用下方时间条。沉浸三维也使用参数抽屉。顶栏放不下时可以横向滑动寻找入口。

看懂按钮、开关与折叠入口

  • 连排按钮用于选择一个模式或视图，蓝色选中项表示当前选择；普通链接进入另一页面。
  • 开关文字在左、控制器在右，点文字或开关均可切换；蓝色表示开启。较长文字可以换行。灰色表示关闭；变淡且无法操作的控件才是禁用，需要先满足当前模式条件。
  • 箭头标题展开同栏的子级设置，位于平级按钮和开关之后。太阳实验的“显示辅助”先列轨迹、辅助线和月球叠加，最后是“日影与杆尖影迹”。关联图解的“空间模型”位于入口列表末尾。
  • 关联图解按当前天体和标签提供相关菜单，不显示无关的太阳轨迹或日影控制；日晷与日行迹属于太阳任务。

播放一天还是播放日期

  1. 展开“播放与快捷时刻”，先选择播放对象：比较同一天选“一天内的时刻”，比较不同日期选“日期（固定时刻）”。
  2. 设定速度和循环，再点击时间条的播放按钮。手动修改日期或时刻会暂停，便于读数。
  3. 太阳日期滑块覆盖本年；月球日期滑块覆盖本月，跨月可用日历，或在播放设置中调整月份。日行迹播放全年日期，固定观测时刻另由自己的时间条设置。
  4. 日出、最高和日落等快捷按钮跳到当前条件计算出的事件；“当日无”表示这一天没有对应的几何事件。

返回撤回，前进重做

模式、图解、天体选择和参数调整进入浏览器历史；一次连续滑条调整合并为一步。曲线拖动若改变日期或时刻也可撤回。菜单展开、收起、滚动和纯相机旋转、缩放不占步骤。恢复设置会暂停播放；撤回后做新调整时，原来的前进分支按浏览器规则替换。返回超过本页最早记录会离开页面。

键盘与操作反馈

用Tab移动焦点，开关获得焦点后按空格切换，折叠标题可用Enter或空格展开；支持键盘的画布使用方向键，缩放方式看该视图提示。菜单和切换项有轻微回弹，读数无需等动画结束才更新。开启系统“减少动态效果”可直接切换。若出现首次展开停顿，请记录具体菜单与浏览器，按故障反馈方式报告。

先弄清三个不同操作

操作 在哪里调 改变什么 先检查什么
观测时刻 图形下方时刻滑块、时间输入框、±5分 同一日期内的天体位置和日影 日期、地点保持不变
观测日期 下方日期滑块或日历 不同日期的太阳或月球条件 要逐日比较时固定观测时刻
观察地点 参数 → 日期与地点 纬度、经度及当地天空 日期与时刻是否沿用原设置
旋转画面 可旋转视图中拖动，或使用方向键 通常只改变相机 球形地球是否开启“联动观察地点”

本项目主时间条使用当地真太阳时。日晷和日行迹提供固定UTC偏移的钟表时对照；做记录时写明时间依据。画面上的正午读数不能直接当作所在城市手机钟表的12:00。滑动日期前先暂停播放，跨月或跨年用日历确认完整日期。

读数怎么读

读数 含义 记录时注意
太阳／月球高度 天体相对当地地平面的夹角，地平线0°，天顶90° 负值表示地平线下，不是计算出错
方位角 从正北顺时针量起，东90°、南180°、西270° 太阳在天顶或观察者在极点附近时，方位可能敏感或不唯一
太阳赤纬／直射纬度 太阳相对赤道的位置，北为正、南为负 与观察地点纬度分别记录；太阳高度高不代表直射本地
地平线上时长 天体几何中心位于0°地平线上方的时间 未加入大气折射与太阳视半径，不等于肉眼日出日落口径
月面照明比例 从地心看月球可见圆面中被太阳照亮的比例 与当地可见时间、亮面朝向和是否能肉眼看到分别讨论
影长／距离 单位分别看m、cm、km或AU；AU约为1.496亿千米 读数是真实计算量，画面有缩放，不能拿像素作为物理长度

三种时间依据不要混用

当地真太阳时：跟随当地太阳时角，适合比较一天中的太阳位置。固定UTC偏移的钟表时：用于日晷与日行迹对照，需填写偏移，项目不自动套用地区夏令时。UTC：独立三维页使用的统一时刻；它不随观察地点改变。

在两个不同经度的地点分别设置12:00真太阳时，是比较各自的当地正午，通常不是比较同一个物理瞬间。做三维对照时用系统同步后的UTC，不要手工把两边数字设为一样。

课堂与自主学习路线

安排 顺序 完成后交什么
10分钟入门 北京的一天 → 同时刻换季节 → 用高度曲线核对 5个时刻的高度记录与一条有条件的结论
20分钟太阳专题 季节比较 → 纬度比较 → 日影 → 日晷 两组控制变量记录；说明显示放大与实际影长的区别
20分钟月球专题 月相原理 → 固定时刻逐日 → 月球天空 → 同UTC三维对照 一月内的日期／照明比例表；区分月相变化与每天升落
30分钟综合探究 钟表时日行迹 → 真太阳时比较 → 理想成因实验 → 空间关系核对 注明时间依据的图形记录；解释哪一个变量产生了哪一种变化

教师可先投屏演示一次，再让学生按同一条件复现。每组先负责一个变量；交流时把观察数据与解释分开。结果不同先比对设置，再讨论模型。不要要求学生从经过缩放的三维球体测量真实距离。

太阳任务：一天、季节与纬度

  1. 选择“太阳 → 空间视图”。固定地点和日期，把时刻从上午拖到下午，记录太阳最高时的位置与高度。点击“白昼时长”旁的 ⓘ，查看计算标准。
  2. 展开“播放与快捷时刻”，点击日出、当日最高或日落，比较三个时刻的画面。
  3. 保持地点不变，选夏至和冬至；每次使用同一观测时刻，记录高度和昼长。要连续比较全年，播放对象选“日期（固定时刻）”，拖动日期或按天播放。
  4. 回到同一日期与时刻，只拖动纬度，再比较赤道、北京和高纬地点。不要在这一步同时更改日期。
  5. 进入“关联图解”，按任务切换“全天高度曲线”“日出日落”“直射点与昼夜”或“地轴与地平面”。点击高度曲线或升落结果，查看对应时刻。
  6. 在“直射点与昼夜 → 球面视图”选择拖动方式。默认“仅旋转视角”只改变观看方向，地点、物理时刻与太阳直射点不变；“联动观察地点”会改变经纬度，保持当地真太阳时，因此对应UTC与太阳直射点可能变化。可点“对准观察地点”复位视角；单击球面仍会选择新地点。

示例：在北京比较季节

  1. 地点选北京，模式选日期观测；用分至日按钮选本年的夏至。
  2. 观测时刻设为12:00当地真太阳时，记录太阳高度、日内最高位置和白昼时长。
  3. 只把日期改为冬至，再记录相同内容。对北京应能看到夏至太阳更高、白昼更长；换到南半球时不要照搬北半球季节结论。
  4. 切到“日出日落”读两日的升落方位；切到“全天高度曲线”比较地平线上方的时段。极区可能没有普通日出或日落，应读极昼、极夜提示。
  5. 要研究纬度，再恢复其中一个日期与12:00，单独修改纬度。记录太阳相对天顶的位置；不要同时移动日期滑块。

理想实验用于单独调整太阳赤纬，日期观测使用真实星历。实验结束后切回日期观测，避免带着理想条件做真实日期比较。“四图对照”适合看共同条件下的高度、升落、昼夜与地平面关系；需要读小字时切回单图。

把四张关联图解一起对照

  1. 选定地点、真实日期和当地真太阳时，暂停播放，进入关联图解的太阳模式。
  2. 选择“四图对照”：同一条件下查看直射点与昼夜、全天高度曲线、升落方位和地轴与地平面。
  3. 只拖动时刻，记录哪个图随时刻变化、哪个量主要由日期与纬度决定；再固定时刻只改日期。
  4. 小图文字省略时切到对应单图。球面地球与地轴图可独立旋转；先确认球面拖动选择“仅旋转视角”，避免意外改变观察地点。
  5. 若要看一边原图、一边三维，先退出四图对照，再开启“三维对照”。真实日期条件才能同步三维；理想太阳条件不与真实星历混合。

记录表同时写下原图标签与三维模式。两边由同一物理时刻驱动，不要把当地真太阳时和UTC数字强行设成相同。

日影任务：让影子与影尖轨迹更清楚

  1. 选择“太阳 → 俯视日影”，再展开“显示辅助 → 日影与杆尖影迹”。
  2. 开启地面影子，设置竖直立杆高度。影子太短时增大“日影地面放大”；影尖超出画面时减小倍率。
  3. 开启“全天杆尖影迹”，拖动时刻或点击轨迹，记录上午、正午附近、下午的影尖位置。
  4. 比较杆高时保持地点、日期、时刻和显示倍率不变，分别记录影长；不要只比较画面上的线段长度。

怎么判断变化来自哪里

把上午、当地正午、下午各记录一次：太阳方向、太阳高度、影子方向、影长。影子方向与太阳的水平来向相反；同一根竖直杆在太阳更高时影子更短。更改“地面放大”只改变显示比例，不改变真实影长。比较两根杆时保持显示倍率一致，以数值为准。

太阳在地平线下时没有直射日影；接近地平线时影子可能远超画面。出现裁切箭头时，减小放大倍率或选择更高的太阳位置，不要把出画的影子当作没有影子。

任务单：方向、影长与季节分开比较

  1. 固定北京、同一日期和同一杆高，取09:00、12:00、15:00。记录高度、太阳方位、影子方向和影长，检查影子是否背向太阳。
  2. 把时刻恢复12:00，只改日期为夏至、冬至。太阳更高时，同一竖直杆的影子通常更短；若换到其他纬度，先用读数确认关系。
  3. 固定一个有影子的时刻，把杆高加倍。实际影长也应按比例变化；再只改地面放大倍率，实际影长读数应不变。
  4. 开启影尖轨迹，逐个点选上午、正午、下午，核对当前影尖落在轨迹上。太阳在地平线下时没有直射太阳形成的杆影；接近地平线时影子可能很长并超出画面。

太阳在天顶附近时影子接近零，属于几何结果。要看清短影，可以放大显示，不要为得到长影而改变原来要研究的时刻。

月球任务：按天看月相，按时刻看天空

  1. 选择“月相”，设置地点与月份，固定观测时刻。拖动本月日期滑块，记录月相名称和可见月面照明比例。
  2. 想看一天内的位置变化，点击“月球天空”，再选择空间、俯视方位、地平或仰望天空视角。播放对象改为“一天内的时刻”。
  3. 从月球模式进入“关联图解”，选择“月相与关系”“逐日照明比例”或“月出月落”。先确认标题显示“月球 · 关联图解”，然后直接在这一页调整日期与时刻。
  4. 选择“行星伴月”标签，选一颗行星；固定地点与时刻，按日期比较角距。也可使用“找未来30天最靠近日”，随后阅读高度及可见性提示。

月相原理图与逐日观察分别怎么用

  1. 进入月相画面，先看地球、轨道上的月球、平行太阳光和旁边的月面示意；球体大小与距离不是实际比例。
  2. 用鼠标或手指拖动轨道附近的月球，连续查看相位变化。这个操作同时改变实际日期与时刻；想严格比较“不同日期、同一时刻”，应改用下方日期滑块并保持时刻不变。
  3. 每隔几天记录一次日期、月相名称和照明比例。月相周期约29.53天，不等于一个历月；跨月时继续使用日历，不要要求每月1日恰好是新月。
  4. 切到月球天空，观察同一天里月球的高度和升落；再改日期比较同一时刻。月球日轨迹仅覆盖该日00:00—24:00，两端通常不闭合。

原理图的大月面是固定朝向示意，不能用它直接判断本地天空里亮面朝左还是朝右。真实天空方向请看“仰望天空”；南北半球及不同朝向会改变月面在画面中的姿态。行星伴月的角距接近不意味着一定肉眼可见，还要看高度、日照条件和页面提示。

任务单：一个月里固定时刻观察

  1. 选定地点、月份与20:00当地真太阳时，暂停播放。每隔约3天改变日期，记录月相名称、照明比例、月球高度与“地平线下”等提示。
  2. 找到最接近新月、上弦、满月、下弦的日期，再用相邻日期细看。不要预设这些月相必定发生在农历或公历某一天；按本页星历读数判断。
  3. 选一个月球在地平线上的日期，保持日期不变，拖动一天内的时刻。比较月相比例与天空位置变化：升落是日内运动，月相的主要周期是约29.53天，但同一天内照明也会缓慢变化。
  4. 切“月相”原理图或三维日地月，在同一时刻核对照明比例。外部相机看到的亮面、固定朝向月相图与本地天空里月面的旋转方向，分别代表不同观察方式。

不要把“满月”解释为月球自己发光，也不要把月相解释为地球影子遮住月球；这里的常规月相图展示太阳照明与观察方向，日月食另有遮挡条件，本模型不模拟食。

仰望天空任务：同时调整方向与时刻

  1. 在太阳界面直接选择“仰望天空”；在月相界面先点击“月球天空”，再选“仰望天空”。
  2. 用方位滑块或东南西北按钮转向，用时刻滑块改变观测时间。这两个操作分别改变朝向和时刻。
  3. 点击参数区的天体名称，让画面转向它。月面亮边会随当地天空方向转动；月相原理图仍是固定朝向示意。若天体未出现在画面中，先读“身后”或“地平线下”等位置提示。
  4. 在太阳界面需要对比月球时，展开“显示辅助”，开启“叠加月球视运动”，再固定地点、日期与时刻进行比较。

记录时把“朝向”和“时刻”分开：先固定时刻，只改变面向方位，找到各天体；再固定朝向，只改变时刻，观察升高、降低或移出视野。白天图中显示的行星是位置提示，不是对肉眼可见性的保证；低于地平线的天体无法从这个地点直接看到。

地面方位参考盘标出北、东、南、西，蓝点表示观察者站位，金色箭头表示正前方。拖动转身时，地面网格和方位字一起改变投影：例如面向南时东在左、西在右，转向东时北在左。它是帮助辨认朝向的示意，不是天体轨道，也不改变天体高度；极点方位采用参考约定。

轨迹为什么没有接到地平线？

点击仰望天空视角上方“轨迹说明”。图中地平线是高度0°，不是天体会落到的实体表面。前方半球的左右视野边界在正投影中呈弧形；轨迹转到身后就会截断，截断高度不一定为0°。此外，月球当日00:00与24:00端点可能仍在天空中，不一定是升落时刻。

可固定北京夏至附近的日期，先面向南，再转向东、北、西。东北日出和西北日落处于面向南时的身后，因此前方太阳轨迹两端可以高于地平线。只有天体中心穿越高度0°，才是本项目的几何升落。

任务单：月球与行星的同场观察

  1. 先固定地点、日期与时刻，用四个方位按钮查找太阳、月球和行星，再点击天体名称对准它。读高度，确认是否在地平线上方。
  2. 保持朝向不变，只拖动时刻，记录天体何时进入、离开前方半球。把“在身后”与“在地平线下”分开：前者可转身看，后者在该地点该时刻不能直接看见。
  3. 在月球模式开启行星伴月，记录月球与所选行星的角距，再查看双方高度和日照条件。角距小只表示方向接近，不代表物理距离接近，也不保证肉眼可见。

日晷任务：比较两种装置

画面上方选择日晷类型与“立体装置／盘面与安装”。晷上读时紧贴图形，时间和日期只用下方控制条。立体视图默认拖动旋转装置，双指或滚轮缩放；切换“拖影调时”后才通过拖影改变时刻。复位视角不改变地点与观测时间。参数菜单按观测地点、装置参数、钟表时对照和制作原理分组。

  1. 在太阳实验台的“关联图解”菜单中点击“日晷实验台”，进入独立实验页；再用页面顶部按钮选择水平日晷或赤道日晷。
  2. 先选择“水平日晷”，设置地点和日期，拖动图形下方的时刻滑块。图形上方显示当前装置的“晷上读时”，类型切换后读数与说明同步改变；夜间会提示无直射日影。选择“拖影调时”后可拖动影子或点击刻度，也可播放一天。
  3. 固定日期与时刻，只改变“晷针长度”，记录影线变化和读时；再切换“赤道日晷”，重复同样的比较。
  4. 切到“盘面与安装”查看安装图。需要动手制作时展开“制作、安装与原理”；需要对照钟表时，展开“钟表时对照”，设置 UTC 偏移并读取对照结果。

动手比较的顺序

先固定地点与日期，分别选上午、正午附近和下午，记录晷上读时、影线方向和当前装置类型。拖动旋转只改变看装置的角度；开启“拖影调时”才改变观测时刻。改变针长时，影线长度会变化，不能把这个变化误读为时间变化。

水平日晷的盘面水平，晷针方向平行地轴；赤道日晷的盘面平行赤道面，针与盘面垂直。安装时按本地纬度和南北半球设置，而不是仅凭屏幕上看起来的倾斜。对照钟表时先填正确UTC偏移，注意本项目不自动处理夏令时。读数提示“无直射日影”或不可读时，先改到太阳在地平线上的时刻，再检查装置安装条件。

任务单：装置、影子和钟表读数

  1. 选北京和太阳在地平线上的时刻，先用“立体装置”旋转查看盘面和晷针。水平日晷是盘面水平、针平行地轴；赤道日晷是盘面平行赤道、针垂直盘面。
  2. 记录09:00、12:00、15:00三个真太阳时的影线和晷上读时。刻度受装置类型影响，不要用水平日晷的刻度规律套到赤道盘。
  3. 切“拖影调时”，拖动影子后看下方时刻是否同步；再切回旋转装置，检查旋转不应改变日期或时刻。
  4. 填写钟表时对照的UTC偏移，分别记录晷上读时和钟表时。差异需要结合经度与均时差解释，不能直接认定晷坏了。跨季节时查看赤道盘受光面与不可读提示。
  5. 比较针长时固定其余条件。针长改变影线长度，而影线方向所对应的刻度不应因此变成另一个时刻。

日行迹任务：观察全年轨迹与“8”字成因

  1. 在太阳页面顶部的小字导航中点击“日行迹”，进入独立实验页。原菜单入口也继续保留。
  2. 参数区把“固定时刻的依据”选为钟表时，设置 UTC 偏移；在图形下方设置每日固定观测时刻。拖动日期或逐日播放，观察标记沿全年轨迹的位置。
  3. 保持地点和时间依据不变，分别设置 09:00、12:00、15:00；也可开启三个时刻的叠加比较。需要看不同方向时拖动三维图，或使用“重置天空视角”。
  4. 再把依据切到“当地真太阳时”，记录轨迹怎样改变；每次记录中写明采用哪一种时间依据。
  5. 展开“高级实验 · ‘8’字的成因”，启用理想成因实验。先只把倾角调到 0，再恢复参考参数；然后只把偏心率调到 0，再恢复。最后可把两者都调到 0 作比较。
  6. 调参数时只滚动参数框，全年图形始终保留在上方或旁边。完成成因实验后关闭理想开关，再继续真实日期观察。

怎样记录成因比较

先在真实日期模式完成一整年、同一钟表时的观察，再启用理想成因实验。记录每一轮的地点、时间依据、固定时刻、倾角、偏心率和图形特征；每轮只改一个参数，结束后恢复参考参数。把倾角或偏心率设为0是在理想模型中隔离某种影响，不是在修改真实年份的星历。

改观测时刻时，先观察太阳在本地天空的位置和投影方向，再比较整条轨迹。三维投影可能使线条重叠，可旋转查看或换坐标视图。虚线表示地平线以下的部分；当天的太阳点不等于全年所有日期都可看见太阳。固定当地真太阳时与固定钟表时使用不同时间依据，必须分开记录。

任务单：为什么会有“8”字

  1. 先关闭理想实验，固定地点、钟表时依据、UTC偏移与12:00。遍历全年，记录几个分至日附近的点与曲线位置，注意虚线处在地平线下。
  2. 把时间改成09:00再改成15:00。先比较轨迹在天空中的位置，再旋转三维查看形状；投影重叠不代表时刻设置没生效。
  3. 恢复同一时刻，改为当地真太阳时。此时太阳时角固定，均时差造成的东西向年度摆动被消除，不能要求仍出现钟表时下相同的“8”字。
  4. 在理想成因实验中先记录参考状态，再只将倾角设0；恢复参考值，再只将偏心率设0；最后两者都设0。每一步都用相同地点、时刻和投影比较，写下曲线哪些部分改变。

“大环在下、小环在上”不能脱离坐标和观看方向直接判断。相机旋转、时刻与投影会改变屏幕上的上下关系；先看轴标、月份和选中的坐标系统。

太阳系三维任务：区分空间运动与天空视运动

入口在“实验台 → 关联图解 → 空间模型”，或关联图解页的“空间模型”菜单；也可直接点击顶栏“三维天空”。选择“太阳系三维模型”看八大行星，选择“日地月空间关系”直接看地球与月球。这个页面使用独立的 UTC 时间，不改变原实验台的地点、日期或时刻。

  1. 先选“太阳系”，暂停播放，在参数区选择一颗行星，读出平均太阳距离、平均公转周期和半径。点蓝色“靠近…观察”按钮看它的球体；点“太阳系”回到总览。
  2. 拖动画面旋转相机，滚轮或双指缩放。旋转只改变观察角度，不改变日期或真实天体坐标；画面右上角复位按钮恢复当前视图。电脑也可用方向键旋转、加减键缩放。
  3. 在图形下方拖动日期轴，或使用日历定位。日历定位到所选日期的12:00 UTC，连续滑动和播放保留一天以内的小数时间；查看日期旁的UTC时刻，不要把它当作当地真太阳时。
  4. 固定相机，设置每秒推进的天数，点击播放，比较同一时间间隔内内外行星的运动。取消“循环本年”后，到本年日期轴末端自动停止。跨年观察先用日历选择目标年。
  5. 切换“日地月”，开启“平行太阳光线”，比较太阳方向箭头与光线方向：箭头指向太阳，光线沿相反方向到达地球和月球。拖动日期，观察月球空间位置与地心月相亮面比例；球面上的外部相机所见亮面不能直接当作地球上所见月相。
  6. 手机点击标题旁“参数”打开侧拉菜单，调完后关闭再继续看图。触屏拖动实时旋转，双指缩放不会改动日期。

沉浸式全屏观察：保留控制，让画面占主位

进入沉浸式太阳系

  1. 链接打开满窗口布局；三维页的“沉浸观察”使用网页内布局，不请求浏览器系统全屏，因此不会触发系统全屏提示。退出沉浸只恢复布局。
  2. 顶部保留太阳系／日地月切换，底部保留UTC、播放、日期与滑条。详细参数点击右上角“参数”打开；关闭菜单即可继续旋转和缩放。没有第二套时间控制。
  3. 先暂停，转动相机找到要看的天体，再点名称或通过“观察 → 天体近景”靠近。需要舒缓地观察位置变化，在参数里选2天／秒；它是时间加速演示，不是实时天体运动。
  4. 开启轨道便于辨认公转路径；需要干净画面时关闭轨道或名称。日地月中开启“地轴与赤道”，分清红色地轴、蓝色赤道圈与黄道参考面。
  5. 按“退出沉浸”返回正常布局；键盘Esc先关闭已打开的参数菜单，再退出沉浸。退出只改变布局，不重置天体、相机或UTC，也不自动开始播放。

背景目录包含HYG的61,816颗恒星及J2000方向，普通模式显示视星等≤6.5的8,920颗，沉浸模式扩展至≤8.5，按星等呈现明暗，并以色指数近似蓝白与暖色差别。空间视角不加入大气闪烁；星点柔光、大小与曝光是显示处理，不表示恒星实际直径，也不用于精密测位。 这一模式共用原来的星历与渲染器，不额外启用自动绕行相机。先固定相机再播放，才能把真正的位置变化与观看角度变化分开。

卫星、小行星与真实星云影像

  1. 进入沉浸模式，打开右下角“观察 → 太阳系与深空细节”。卫星群、主带小行星、周期彗星和星云背景可以分别开关。新增对象默认只画点，不显示名称，避免覆盖图形。
  2. 在太阳系总览比较各行星附近的卫星群；水星、金星没有已知天然卫星。选择一颗行星后，点“观察所选行星卫星群”，系统会调整相机，让这颗行星及其可用卫星数据的点群更容易看清；点太阳系回到总览。
  3. 当前快照包含JPL轨道表中八大行星的455颗卫星。它是可用轨道数据的覆盖范围，不是随时更新的全球发现总数。除月球与木星四大卫星外，用固定平均轨道要素近似运动；可观察顺逆行和空间分布，不用于预测掩食或精确相遇时刻。
  4. 主带层包含按JPL绝对星等筛选的1,200颗小行星，并非整个小行星带；彗星层包含12颗椭圆轨道周期彗星。两类标记只在太阳系总览显示，日期仍与原UTC控制共用；不能把点的大小、亮度或压缩距离当作真实观测量。
  5. 星云背景默认关闭；可选的“星云影像背景”使用真实公开望远镜影像，在对象大致方向放大显示，屏幕范围不是实际角直径。点“查看真实星云影像”，可切换猎户座、环状星云及船底座星云中的神秘山，查看原始公开影像和来源。
  6. 星云是远处星际气体与尘埃结构，不是行星卫星，也不在太阳系内部。这里的多波段与处理配色影像不是肉眼所见；关闭星云背景后，可以继续用恒星目录参考天空方向。Esc先关闭影像窗口，再退出沉浸模式。

比较卫星时先暂停并固定相机；再只改变UTC日期。新增点群是独立展示层，不替换原实验台的地理读数、月相和行星位置。想观察本地升落仍回到原实验台。

放大前后怎样看卫星

  1. 暂停日期播放，选中地球或木星，进入近景；在“观察”菜单开启行星卫星群，需要时使用“观察所选行星卫星群”。
  2. 固定UTC，只改变缩放，观察行星与卫星点一起随透视变大或变小；不要把光点直径当作卫星真实直径。
  3. 再固定相机，推进日期，区分卫星的运动与相机的变化。点群没有名称，具体对象识别不能只靠大小。
  4. 要看月球表面示意，选择月球近景；要判断地球所见月相，结合地心照明读数与原月相图，外部相机亮面不是同一种视角。

相机、历史轨迹和月球近景

  1. 点击三维画面右下角“观察”。“立体”用于一般观察，“俯视”从固定J2000黄道北侧看空间关系，“侧视”接近参考平面；这些只是相机预设，不改变星历或观测日期。也可以继续手动旋转，按复位回到当前对象的默认取景。
  2. 在“天体近景”选择行星或月球。月球近景仍是日地月视图中的外部相机，不能把屏幕上的月面亮暗直接当作地球所见月相。读数卡片显示月球实际地心距离和星历地心月面照明；月球的约27.32天恒星月与约29.53天月相周期不同。
  3. 开启“历史轨迹”，选择过去7、30、90或365天。它只绘制当前选中行星的过去路径；日地月视图则绘制月球过去7、30或90天的地心路径。蓝灰端较早，亮端是当前UTC，拖动日期后回看区间随之移动。完整轨道线是另一个开关，它用于整体路径参照，不代表历史区间。
  4. 固定相机和回看跨度，改变日期，记录历史区间、当前UTC和选中天体。切换所选行星比较轨道形状与同一跨度内走过的部分。只比较教学模型中的方向和相对变化；距离经过压缩，不能用屏幕弧长测量真实速度。
  5. 开启“黄道参考面”辨认轨道离面方向。参考面是固定J2000黄道，日地月视图以地心为原点平移显示；它不是当地地平面，也不是每颗行星或月球自己的轨道面。
  6. “显示真实读数”控制画面中的信息卡。行星当前距日读数来自实际物理向量，与左侧平均太阳距离不同；月球用地心千米。需要更清爽的画面时关闭卡片。小对照画面优先保留图形，极矮小图隐藏读数卡片，仍保留可滚动的“观察”菜单；拖动旋转仍可用，完整操作可进入独立三维页。

原有图解与三维一起对照

  1. 进入“关联图解”，选择太阳或月相，再选择一张已有图解，点击标题旁“三维对照”。也可以从三维页点击“原图对照”进入。原图解保留在一侧，三维空间关系显示在另一侧。
  2. 地点、日期和时刻仍用原图解的参数菜单与下方控制条。主控制显示当地真太阳时，系统按经度及均时差换算同一 UTC 后更新三维；两边代表同一实际时刻，不能直接把当地真太阳时的数字当作 UTC。
  3. 太阳图解对应三维太阳系，月球图解对应三维日地月。拖动三维只改变相机；点击行星名称可以看近景，复位返回整体。它不会改变原图解的地点、时刻或地理读数。
  4. 固定地点和日期，拖动时刻，先读原图中的太阳高度、升落或月相，再看三维位置与受光方向。固定时刻后拖动日期，记录两侧共同变化。三维大小、距离与纹理是示意，地球自转与地轴按同一UTC计算，当地昼夜、季节与月面朝向以原图解读数为准。
  5. 桌面左右排列，较高的手机竖屏上下排列；下方仍只有原来的时间工作台。再次点击“三维对照”关闭三维。理想太阳实验和“四图对照”不叠加三维；先切回日期观测与单张图解，再开启。

独立三维页的辅助二维参照

  1. 在画面上方选“太阳系”或“日地月”，再点“参照”。这是两个不同层级：前者选观察对象，后者选画面布局。点“三维”返回单画面，所选日期不变。
  2. 二维一侧选“空间俯视”：查看同一星历时刻的黄道平面投影。三维可旋转，二维始终从黄道北侧俯视，帮助辨认空间视角造成的投影变化。总览以太阳为原点，日地月以地球为原点；月轨的离面高度被投影掉，不代表轨道与黄道完全重合。
  3. 二维一侧选“本地天空”：查看太阳、月球以及选中行星的方位与高度。地球不作为天上可见的行星绘制。打开参数菜单的“本地天空的观察地点”，调整纬度与经度；保持下方UTC时刻不变，比较南北半球或不同经度的天空。它沿用原网站的坐标计算口径，但不是另一套独立运行的实验台。
  4. 拖动唯一的日期轴，两侧同步更新；相机旋转不改变天空高度或照明比例。分别记录UTC时刻、观察地点、三维选中天体、天空高度及方位。不把UTC读数当作原实验台的当地真太阳时。
  5. 日地月模式的地心月面照明比例来自同一星历快照，不由外部相机看到的月球亮面推算。极点或天顶附近方位可能不唯一或敏感；高度读数仍可用于比较。
  6. 桌面左右对照，高度足够的手机竖屏上下对照，短屏保留左右布局，日期条始终独立在下方。二维图中的名称不足以摆下时优先保留读数；需要看近景时切回“三维”并聚焦行星。

行星增加了示意陨坑、云带、木星旋涡、土星环分带和火星极冠；地球沿用本地纹理并增加克制的受光大气边缘。它们用于辨识外观，不能读取真实地形、天气、极冠季节变化或当天表面影像。原星历位置、光照方向和大小缩放规则不由这些纹理改变。

先分清参考面、太阳方向和显示比例

  • 黄道参考面是固定J2000空间参考，不是赤道面或所在地的地平面。箭头指向太阳，平行光线从太阳方向射来；箭头画在参考面附近不代表太阳直射赤道。
  • 判断直射纬度，应读取太阳关联图解的太阳直射点纬度，并与地轴、赤道圈一起比较。春秋分附近直射赤道，六月至日前后接近北回归线，十二月至日前后接近南回归线；不能仅凭相机截图判断。
  • 卫星位置和行星距离经过教学尺度映射，点的大小不是物理半径。聚焦行星后再缩放，卫星点会随透视缩放；比较真实距离请读数，不量像素。
  • 正常宽屏默认显示参数侧栏，可点侧栏顶部“收起菜单”扩大画面；沉浸模式始终将参数放进抽屉。退出沉浸不重置UTC或相机。

记录什么，避免误读什么

每次记录 UTC 日期和时刻、所选视图、选中天体、推进天数，以及固定相机后观察到的位置变化。轨道距离经过非线性压缩，天体大小独立放大；不能用屏幕长度求真实距离或体积。太阳距离和周期卡片给的是平均参考值，不是当前瞬时距离。日地月另有独立比例，不能与总览像素直接比较。

三维主体用于空间关系观察，辅助“本地天空”提供高度和方位；本页不提供完整本地升落事件搜索，不模拟食的遮挡，地球已用恒星时与坐标变换校准自转、纹理经度和地轴方向；其他天体表面姿态仍为示意。要观察日出、月相的本地朝向或地理昼夜，请回到原实验台和关联图解。浏览器无法建立 WebGL 时，本页显示返回入口；原实验台继续可用。

操作遇到问题时

  1. 找不到滑块：在参数框内部滚动，展开相应菜单；常用时刻与日期滑块位于图形下方。
  2. 日期不能调：检查太阳是否处于“理想实验”，在“演示方式”（关联图解中为“太阳计算方式”）切回“日期观测”。
  3. 影子或天体没画出来：先查看当前时刻及页面位置提示，再调整时刻或朝向；需要理解几何条件时打开“项目介绍与地理模型说明”。
  4. 切换页面后拿不准当前设置：先看标题中的太阳／月球、地点、日期和时刻。各天体保存自己的状态，跨页访问会沿用当前会话设置。
  5. 仍有异常：通过“联系作者 · 欢迎反馈”提供模块、地点、日期、时刻、操作步骤及设备／浏览器信息。

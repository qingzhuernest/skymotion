## 实际修改

搜索界面负责展示；runtime.js 独立负责资料、版本和 Worker 生命周期；search.js 负责查询分析、倒排检索、答案选择与候选融合。一个问题只分析一次，预计算词项、倒排列表及长度权重。知识、用法和开发问题自动区分，保留一个搜索输入框。

候选采用去重融合，弱语义结果不会抹掉有效文字结果。语义主答案仍须同时满足得分、分差和独立文字证据；文字证据可查询整个索引，不必恰好位于文字 Top 5。修正英语词边界、部分词形及短追问范围；长问题不会因为含有“保存”就被误作保存上一轮实验。

资料和索引采用重新验证缓存，界面与 Worker 使用同一资源版本。共享模型准备支持提前加载；取消只影响对应问题，迟到结果与旧 Worker 错误不会污染新请求，失败可重试。Worker 保持串行推理，并支持明确取消某个排队请求。

新增全仓库源码解析与本地素材引用检查，CI 同步运行；模型索引未变时可以验证后只重建运行代码，正文变化则必须重建向量索引。

## 验证结果

- 633 条来源派生问题、35 条短问题与双语边界检查通过。
- 实际 BGE 浏览器推理、自动分类、报告案例、短问题、系统性回归、欢迎页入口通过。
- 共享准备、并发排队、取消、超时与失败重试、旧结果隔离、零分块去重和安全 DOM 检查通过。
- 文档生成、章节操作链接、14 组双语页面检查通过。
- 三维模型、地球坐标框架、探索状态、会话及参考对象回归通过。
- 月球模块在组合浏览器运行中曾于设置弹窗步骤超时；未修改该模块或降低断言，单独运行完整相关用例后通过。

这些结果来自本地 Chromium 与 Node/Python 检查，不能代替全部 Safari 设备、所有自然语言表达或端到端网络环境的验证。

## 本地性能测量

相同旧版 633 条资料、相同十个问题、每题预热 20 次并计时 200 次：平均文字检索由约 5.84 ms 降到 0.38 ms。更新为当前更完整的双语手册正文后，在浏览器测试并行负载下平均约 1.20 ms；索引构建约 561 ms。后者语料和负载不同，不作为严格同条件对比。

以上仅指本地文字检索计算，未包含下载、模型初始化、语义推理或页面加载；没有据此宣称整站加载提速相同比例。正式与预览发布状态以部署系统的成功结果为准。

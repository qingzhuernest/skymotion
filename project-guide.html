项目定位与页面入口

天体视运动实验室用于把地点、日期、时间与可核对的天空和空间图解联系起来。核心计算在浏览器执行，不依赖账号或实时星历接口。顶部只有欢迎页、实验台、文档中心和三维天空四个主入口。

  1. 初次使用先打开实验台，观察默认太阳场景；需要教学任务时从文档中心进入学习指南。
  2. 需要查按钮、保存范围或具体模块时，使用本手册目录；需要修改代码时进入开发者文档。
  3. 顶部主菜单负责切换主要区域；左侧栏目和图内视角属于当前工作区，不会改写顶部主菜单。

太阳与月球使用顶部并列按钮直接切换，也可聚焦后使用左右方向键。底部时间栏把精确时刻与滑块放在一起，两侧按钮每次调整五分钟；月球优先呈现日期控制。观测条件先显示当前模式、地点和日期，计算与比例说明按需展开。

先读懂界面与控制

页面分为固定主菜单、实验标题、左侧控制区、右侧图形和下方时间栏。桌面可边调边看，宽度不超过760像素时使用参数抽屉。

  1. 在标题旁选择太阳或月相；确认标题下方的经纬度和下方时间栏的日期。
  2. 左侧视图与布局用于选图；观测条件保留原参数；进入自定义后，图中对象用于编辑附加参考和标记。
  3. 需要扩大图形时，使用始终保留的收起菜单；从边缘展开按钮恢复。手机点击参数打开抽屉，设置后关闭回到画面。
  4. 语言按钮切换中英文；它不会重置科学条件。减少动态效果跟随系统设置。

鼠标拖动、滑条拖动和键盘操作具有不同对象：先看当前图位和当前选中对象。不要把移动相机、移动基准地点和移动附加城市混为一谈。

实验台顶部左侧显示标题和地点，随后是主菜单；太阳与月球通过并列的双按钮直接切换。自定义和语言入口保持在顶部右侧，窄屏按可用宽度排列。“三维对照”位于左侧“视图与布局 → 对照与搭建”，可与原科学图共享UTC并排观察。

地点、日期与时间怎样设置

城市预设是设置经纬度的快捷方式。下方公共时间栏控制当前观测；日行迹和地升地落另有专门控制，分别见对应章节。

  1. 在观测条件选择城市，或拖动纬度、经度滑条；需要精确值时再输入数值。纬度北正南负，经度东正西负。
  2. 用日期滑条、前后一天按钮、季节快捷日期或日历设置日期。日历支持跨月、跨年，确认后才应用，取消保持原日期。
  3. 拖动时刻滑条连续观察，使用时间输入或前后五分钟按钮微调。先暂停再进行条件对照。
  4. 使用逐日播放时读清播放对象：按天变日期与日内变时刻不同；循环开关决定到边界后继续还是停止。
量范围与解释

经度−180°至180°；跨日期变更线比较时注意当地日期

怎样选择、替换和组合图

视图目录按天空与日影、关联图解、对照与搭建分组；日行迹归入关联图解，三维对照归入对照与搭建。空间视图、俯视日影、地平视角和仰望天空位于左侧“天空与日影”内部，月球模式显示对应视角；画布上方不再重复这些按钮。组合图的“编辑”入口放在各图标题栏，避免遮住数据和操作提示。普通模式也能打开组合视图；调整内容和排列需要进入自定义。

  1. 点击图名打开单图。组合中点击已显示图名会选中对应图位，点击未显示图名会替换当前图位。
  2. 先点要操作的图窗，看绿色边框与左侧对应项；此后替换操作针对这个图位。
  3. 图名右侧的加入控件新增一个图位；已加入时变为移除。至少保留一张图。
  4. 天空图只有一个目录入口；空间视图、俯视日影、地平视角和仰望天空集中在天空图标题栏。

不是每个独立模块都能嵌入组合。目录中有加入控件的内容才支持加入；地升地落和搭建保留独立场景。

太阳与日影的四个视角

四个视角共享基准地点、日期和时刻。改变视角不应改变这些科学条件。

  1. 空间视图：拖动旋转相机，滚轮或双指缩放，使用复位视角恢复；查看日轨迹、杆和影子。
  2. 俯视日影：从地面上方比较影长、方向和影尖轨迹；显示放大倍率只影响画面尺度。
  3. 地平视角：从地平线附近看升落和高度变化，注意虚线表示地平线下的延伸。
  4. 仰望天空：转动朝向寻找太阳、月球或行星。转头不同于改变观测地点。

显示辅助中的轨迹、角度线、影子、影尖记录和月球叠加按当前模式提供。夜间、极昼、极夜或太阳近地平线时，某些影子读数可能不存在或超出画面。

地球与昼夜、地图和地轴图

地球与昼夜连接太阳方向、直射点、观察地点与昼夜分布；地轴与地平面图连接地轴、赤道面和当地地平面。

  1. 在球面视图与全球平面图间选择。球面拖动默认可以只旋转视角，先检查拖动规则。
  2. 使用取动观测地点或拖动明确的观察点移动地点；选择固定同一UTC瞬间或固定当地真太阳时。
  3. 需要只改纬度或经度时使用移动约束；对准观察地点用于调整相机朝向。
  4. 在地轴图拖动相机核对不同平面关系；用图例识别地轴、赤道面、地平面、天顶和太阳方向。

全天高度曲线

太阳模式横轴是当地真太阳时，纵轴是太阳高度；月球照明图采用另一种横纵轴，不能直接混用。

  1. 沿曲线点选时刻，与下方公共时间栏和天空中的当前位置互相核对。
  2. 在自定义里添加日期对照曲线，用该对象自己的日期滑条或日历改变参考日期。
  3. 添加水平参考线、时刻标记或两点时间与高度差测量，读清起止点和单位。
  4. 比较曲线峰值、过零、全天高于零或低于零的情况；重合曲线可能来自相同条件。

日出日落与月出月落方位

事件按天体中心穿越几何地平线计算，不包含大气折射、山地遮挡或太阳视半径修正。方向基准固定，不通过旋转盘面伪造新读数。

  1. 点击出或落的端点，跳到相应事件时刻。
  2. 按住端点拖向另一个方位，系统保持地点不变并反求能接近目标的日期，各图与下方日期同时更新。
  3. 太阳在当前年份内寻找日期，月球在原日期前后五周内寻找；超出可实现范围时停在最近结果并提示。
  4. 左右键按日调日期；滚轮或双指缩放；Home复位缩放；拖动中Esc取消并恢复原日期。

没有当天事件时没有可拖端点。应先用日期和地点控制寻找有事件的条件。极点不赋予唯一升落方位。

月相、照明比例和行星伴月

切到月相后，系统保留太阳与月球各自设置，并在视图目录提供适合月球的内容。

  1. 月相与关系：观察日地月位置、地球视角亮面和月球轨道相位。
  2. 逐日照明比例：按日期比较月面照明比例，用当前日期点核对月相图。
  3. 月出月落：读取该日一个或两个事件，缺少事件不一定是异常。
  4. 行星伴月：选择行星、检查角距离和地平线位置，使用日期范围搜索时保留其地点和时间依据。

伴月表示方向接近，不是物理碰撞或实际距离接近。搜索结果也不包含天气、地形、背景亮度和目视极限的完整评估。

地升地落的独立控制

在月相模式从关联图解进入地升地落。轨道示意和宇航员视角使用同一个绕月状态；本模块不把实验台日期当作真实月球任务轨道。

  1. 选择绕月观察或固定月面。绕月模式可调位置角、高度、飞行时长和日地月构型。
  2. 点击看地升找到地球从月面边缘出现的位置，再播放或暂停。
  3. 地球在画面外时使用朝向地球或Home；拖动宇航员画面只是转头。
  4. 手机可切换轨道图和宇航员视图；仍从左侧视图与布局返回其他模块，观测条件栏调本模块参数。

固定月面模式禁用绕月位置、高度和飞行播放等不适用控制。模型采用同步自转、球面月球与圆轨道，未模拟天平动和真实地形。

日行迹与成因实验

日行迹显示同一地点全年在固定采样时刻的太阳方向。标题栏标明采样时刻与依据，下方公共时间栏显示当前观察条件。

  1. 选择当地天空三维示意、天空坐标或赤纬与时角等可用投影。
  2. 设置全年采样时刻、固定钟表时或固定真太阳时，以及钟表时的UTC固定偏移。
  3. 需要与公共时刻联动时勾选跟随真太阳时；手动改采样时刻或依据会解除该联动。
  4. 叠加不同固定时刻、地点或参考轨迹；小画幅会减少月份文字，当前月份优先。
  5. 成因实验独立调整地轴倾角和轨道偏心率；完成后回到真实日期模式再解释真实星历。

日晷装置与太阳日影

日晷相关页面和实验台控制提供杆影、水平式与赤道式装置。它们与教学图解共享地点和太阳方向，但显示缩放不等于改变装置尺寸。

  1. 先选择装置或日影视图，再设置纬度、日期、时刻和杆高等适用参数。
  2. 比较轨道、俯视、影尖轨迹或装置视角，使用复位恢复相机。
  3. 核对太阳时和固定时区偏移的读数说明，不把晷面刻度自动解释为本地法定时间。
  4. 太阳低于地平线或光线与晷面无有效交点时，按提示判断可用性，不强求一个读数。

进入自定义与对象编辑

统一开关位于顶部语言按钮旁；进入后保留原观测控制，并启用图中对象、加入或移除图位、布局编辑和搭建工具。不会自动放入一个未说明的参考圈。

  1. 先选需要的图，再从图中对象点击添加对象；使用目标任务的快捷方案，或展开自由工具。
  2. 需要点选位置的工具会给出放置提示；在图上点击，或使用可用的放在中央操作。
  3. 选择列表或图中对象后，在属性中用滑条预览、用输入框精调；对象的显隐与锁定控制分别管理。
  4. 每行更多菜单提供适用的保存、复制、删除；撤销和重做管理对象操作。连续滑条拖动合并为一步，Esc取消正在进行的操作。
  5. 完成自定义保留当前组合，隐藏编辑把手；再次进入可继续编辑。刷新默认回到普通模式，草稿按会话规则恢复。

城市、日期与时刻对照

对照对象附加在基准实验之上。添加城市不会自动移动原观测地点；相同条件的两条曲线可能完全重合。

  1. 同一瞬间不同地点：从添加对象的地点任务选城市并开始；默认按同一UTC瞬间比较。
  2. 选择城市后拖动经纬度；离开预设坐标时自动名称改为自定义地点与坐标，手动命名保持不变。
  3. 在固定UTC与固定当地真太阳时间选择实验依据；跨午夜时读清对照的当地日期。
  4. 选中城市后，各相关图的同一对象突出，其他对照淡化；用设为基准地点才改变原地点。
  5. 同地不同时刻方案可加入早晚标记；用对象时间滑条调整。日期曲线则使用自己的日期，不改公共日期。

独立的地点与时间对照场景还可一次显示当前与前后时刻，或当前与两个对照地点；时间间隔、参考地点和读数由该场景的观测条件管理。

搭建杆、球、圈与测量

搭建实验从空白地面或明确标识的已存场景开始。太阳与月球拥有独立的物体场景；地面是教学模型，不是任意真实地形模拟。

  1. 选择杆、球、参考圈、平面、刻度盘、观察站、标记点或文字，再点击地面放置；可一次添加多个。
  2. 用属性滑条调整位置、尺寸、高度、方向和允许的倾斜。先检查保持竖直、贴合地面、锁定与网格吸附。
  3. 使用圆周、等距、对齐等适用排列；多选后读清对整组或单个物体的操作范围。
  4. 选择相应物体建立距离、角度或影长测量；记录运动时检查轨迹长度和样本范围。
  5. 保留一份场景参考，再只改变一个条件进行对照；增加文字说明记录实验假设。

改变相机不会移动物体。约束会限制可编辑范围；被锁定的物体不能直接拖走。月球光照与日影相关读数应按当前模式说明理解。

布局、顺序与专注观察

多图工作区复用同一批科学画布和一个公共时间栏。最多可以容纳六张适合组合的图；超过四张时纵向滚动，手机通过图名标签切换。

  1. 进入自定义后，从目录加入图；排列与收藏中选择一至四图的快捷数量或常用组合。
  2. 两图可左右并排或上下排列；三图可均衡或主辅布局。拖动把手交换顺序，或使用顺序按钮。
  3. 拖动分隔线预览比例，松手更新画布；精确输入比例允许30%至70%，确认后应用。
  4. 双击图名，或在自定义中点击“专注此图”，临时放大一张图。图名旁始终显示“返回多图 · Esc”；点击它、按Esc或再次双击图名都能返回组合。
  5. 先点击要替换的图，其边框会标出当前图位，再从侧栏选择另一张图；自定义中的图名选择器也可直接替换。撤销与重做布局不等于撤销科学条件。

添加图解只有目录中的一个入口；收藏栏不再重复列出一套添加按钮。完成自定义后保留组合，但隐藏编辑把手和分隔线。

草稿、收藏和完整实验

保存范围分为会话草稿、独立对象或场景存档、布局收藏和完整实验。先选对范围，再判断刷新或换设备后是否还能恢复。

  1. 只收藏排列：打开排列与收藏，保持连同观测与对象保存未勾选，命名后保存组合。
  2. 保存完整实验：勾选该选项，命名后保存；它包括观测状态、布局、当前天体的图中对象和搭建物体。
  3. 点击带完整实验标记的收藏恢复。恢复后暂停播放；无效的完整记录会拒绝应用，不部分覆盖当前实验。
  4. 收藏可重命名、用当前内容更新或删除，最多五项；同名保存用于更新。对象行的独立保存和搭建场景保存仍保留。
  5. 跨设备分享时同时提供文字条件和可用的对象JSON导出；不要把浏览器本地收藏当作云账号同步。
方式保留什么重要边界
会话草稿当前会话中的参考编辑和实验状态关页、存储限制和跨页面行为以提示为准
布局收藏图的种类、顺序、排列与比例不改变日期地点等科学条件
完整实验观测状态、布局、当前天体参考对象和搭建场景当前设备浏览器存储；恢复暂停
独立对象或场景当前图对象或搭建场景与收藏独立，按各入口标注的范围保存

浏览器拒绝存储或空间不足时，系统会提示仅本次访问可用。不要关闭页面后才检查是否保存成功；看到成功状态后再离开。

三维天空与太阳系

三维天空是独立渲染器，使用UTC日期、真实物理向量和教学显示尺度。顶部文档中心与自定义入口保持在固定导航区域。

  1. 太阳系总览中点击行星或侧栏列表选择天体；靠近观察与重置只改变相机。
  2. 切换日地月关系观察照明、姿态和月球轨道。物理距离与显示距离按说明区分。
  3. 通过观察菜单调整相机和显示；拖动旋转、滚轮或双指缩放，键盘方向和缩放键以画面提示为准。
  4. 在参考对照中选择参考平面或当地观察位置，查看同一UTC瞬间的图解。
  5. 调整日期与播放速度，核对UTC、循环范围和停止边界；沉浸模式保留参数抽屉。

星空、卫星、小天体和星云等探索内容按相应选择器提供。不同对象可能使用目录、近似轨道或处理影像，标签、数据来源和影像许可不能替代测量精度说明。

实验台的三维对照可在保留当地科学图的同时打开关联三维场景；共享UTC，但相机独立。WebGL不可用时返回二维实验台继续使用。

撤回、键盘与触屏

浏览器后退前进、对象撤销、布局撤销和相机复位分别作用于不同范围。以按钮名称和当前焦点为准。

  1. 需要恢复观测参数或主要选择时使用浏览器后退与前进；恢复后播放暂停。
  2. 在对象或布局编辑区使用本区撤销重做；连续滑条操作合并记录，Esc取消正在进行的拖动或放置。
  3. Tab按顺序移动焦点；原生滑条可用方向键微调。图形方向键的含义以图内说明为准。
  4. 手机通过参数抽屉与图名标签切换；关闭抽屉后再操作图形。沉浸模式先退出已展开的工具，再按Esc退出沉浸。

操作问题排查与模型边界

先核对当前天体、选中的图位、时间依据、是否开启自定义以及当前选中对象，再判断功能是否失效。

  1. 找不到添加：进入自定义，选对应图，再打开图中对象；并非所有工具在所有图中可用。
  2. 城市名没有跟着变：只有自动名称随坐标变化，手动名称会保留；检查是否改到了基准地点。
  3. 图不联动：检查它是否属于组合、参考对象是否可见、当前比较是否使用相同UTC还是相同真太阳时。
  4. 有空曲线或无事件：核对极昼、极夜、地平线相切、日期范围和地平线下状态，而非先假设程序错误。
  5. 地球看不见：在地升地落使用朝向地球；在三维场景复位相机。观察被遮挡与移出画面是两种不同原因。
  6. 语言或字体失败：按页面提供的重试入口重载，保留当前实验；问题反馈附设备、浏览器、路径和复现步骤。

# Companion panel theme regression

The diagram router reparents companion controls from `.ui-parameters` into `.ui-diagram-details`. Container-scoped theme overrides therefore missed the hardcoded blue and lavender colors in the base component rules. This affected the search button, three reading cards, status text and observation-time action in the lunar companion view.

The component now uses the shared paper, line, muted text and teal action tokens directly, with matching hover behavior. Scientific drawing colors and astronomy calculations are unchanged. `tests/review-followup.cjs` checks computed surfaces, borders and text after real Sun/Moon and diagram selection in both languages at 1280, 960 and 390 pixels.

The production hotfix contains only this theme correction, the targeted regression and refreshed resource cache URLs. Preview workspace features are not part of the production hotfix.

Follow-up: the monthly illumination card also inherited a pale-blue fixed-time marker from the dark-sky lunar key. Scope its paper-card marker to the interface accent without changing scientific plot colors. Regression coverage explicitly selects the monthly illumination tab in both languages at all three viewport widths.

Remove the redundant observation-time shortcut at the user’s request, including its unused binding, focus helper and action styles. The shared bottom timeline remains the only time-control entry for this panel; the note now points to it correctly. Regression checks verify the shortcut is absent and the shared input still updates time without changing the date.

Alignment follow-up: replace the wrapping companion flex toolbar with a single-column grid. Label, full-width select, search action and observation context share one left edge. Date and time form a deliberate row; time basis and coordinates sit on separate lines. Tests check aligned boundaries at desktop, tablet and mobile widths and verify the structured values follow time edits.

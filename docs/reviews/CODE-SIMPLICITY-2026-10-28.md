## 结构问题与后续状态

1. **全局原生 setter 拦截已在同日后续整理中移除。** 45 处字段赋值改用共享的 `setValue` 显式提交；设置面板保留其已有的显式 `syncChoices`。实验状态仍由原模块负责，不生成额外用户事件，也不增加轮询或全站表单扫描。生成器统一依赖顺序；原生 setter、程序赋值、动态选项和历史恢复由相关浏览器检查验证。
2. **共享导航与视图选择的样式已归位。** 2026-10-29 将 style.css 和 pages.css 中的导航、页面链接/操作、视图按钮与相关响应式规则迁入 design-system.css，合并重复默认值；页面文件保留实验布局和科学画布职责。迁移前后在三种页面、手机/桌面宽度的计算样式逐项相同。
3. **对象状态、编辑交互与绘图已分离。** diagram-reference-store.js 负责对象数据、存储和历史；diagram-reference-renderer.js 负责只读绘制、文字定位和命中几何；diagram-tools.js 负责编辑交互与协调。保留一个对象所有者和原科学模型，不以另存数据或通用框架包装替代职责划分。
4. **发布检查已按路径选择。** select-checks.cjs 使用明确的模块分组；纯说明文件不安装浏览器，组合改动合并去重，无法读取差异或未知范围保留原短检查集。完整回归仍只由手动选择。两个部署任务继续复用同一次验证。
5. **行数不是唯一验收标准。** 本次给不变城市选项增加了轻量缓存，增加少量逻辑换取不重复重建 DOM；颜色生成也增加少量维护代码，换取一处定义。不能保证每次有价值的精简都让总行数下降。

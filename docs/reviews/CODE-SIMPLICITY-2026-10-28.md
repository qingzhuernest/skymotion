# 代码精简与产品目标复核 · 2026-10-28

## 结论

当前实现已能承载共享实验工作区、设置、组合图、对象编辑与双语文档，但还不是最简洁或最优的实现。文件归类完成，不等于职责和实现已经完全统一。此次复核落实了可确认的小范围精简，同时保留尚待处理的结构问题；不以压缩写法、机械拆文件或删除验证来制造行数下降。

判断依据是用户已反复确认的目标：改一处共享规则能作用于相关页面；同一条件下控件与科学图一致；设置立即生效；自定义不重复维护同一状态；iPad/手机能正常操作；修改和发布不做无关的全量检查。现行要求已整理到 [PRODUCT.md](../architecture/PRODUCT.md)。

## 结构问题与后续状态

1. **全局原生 setter 拦截已在同日后续整理中移除。** 45 处字段赋值改用共享的 `setValue` 显式提交；设置面板保留其已有的显式 `syncChoices`。实验状态仍由原模块负责，不生成额外用户事件，也不增加轮询或全站表单扫描。生成器统一依赖顺序；原生 setter、程序赋值、动态选项和历史恢复由相关浏览器检查验证。
2. **CSS 尚未完全按职责收敛。** 同日后续整理只移除了两处被相同条件下后续规则覆盖的声明，保留最终字体和滑块目标尺寸。 style.css、pages.css 和 design-system.css 仍包含跨阶段的按钮、菜单与布局规则。应以真实控件的计算样式为基准，逐类迁移外观到共享组件文件，页面只保留布局；不同断点、主题和科学画布规则不能仅凭选择器重复就删除。
3. **对象编辑器职责较重。** diagram-tools.js 同时承担对象操作、校验、历史与 DOM。进一步拆分应沿命令/状态与视图的边界进行，保留一个对象所有者；不为缩短文件而再创建一套对象缓存或一组包装转发函数。
4. **默认发布检查仍是固定的短检查集。** 本次去除了重复运行；按改动路径选择检查仍未实现。若继续优化，应维护少量明确的路径分组，遇到无法确定影响范围的改动扩大检查，手动保留完整回归；不引入难以维护的自动依赖推断系统。
5. **行数不是唯一验收标准。** 本次给不变城市选项增加了轻量缓存，增加少量逻辑换取不重复重建 DOM；颜色生成也增加少量维护代码，换取一处定义。不能保证每次有价值的精简都让总行数下降。

## 验证与范围

针对受影响路径检查：文档生成与颜色单来源、地点/时间对照的原选项节点复用、太阳/月球菜单、共享选择控件和动态面板、主题与设置恢复、旧回归唯一入口、打包与两种部署路径。工作流检查一次验证、两个下游部署任务的依赖关系。

这是一轮产品目标、职责、重复实现和关键交互的复核，不是对全部天文数学、所有源码逐行或所有 Safari 真机的全量认证。没有将尚未完成的结构迁移写成“已完全统一”。
